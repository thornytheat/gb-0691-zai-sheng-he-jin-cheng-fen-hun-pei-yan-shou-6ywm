# 数据定义

元素质量按物料净重×含量汇总；干湿基转换，低于检出限给上下界，不可把未检出当零，配方版本锁定。

输入字段：lot, batch, mass, unit, moisture, element, assay, basis, revision。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

Cu和Zn目标区间为V1教学配方，不外推为生产工艺。缺测元素贡献范围按0–100%计；湿基换干基先除以干物质比例；样例存在只测单元素的料批，因此验收可能待补测。

混配按batch炉次独立计算；同一lot可在不同炉次出现，采信键为(batch,lot,element)，移除批次的试算也仅影响所属炉次。

## 配方版本与验收对照

配方版本与文件规则版本（manifest.rule_version）分离：前者是质量口径，后者是程序/证据格式。
每个配方版本有固定指纹（recipe_digest）；批次标识由文件SHA256、规则版本与配方版本共同确定。

| 版本 | 口径 | Cu 目标 % | Zn 目标 % | 可配最大水分 | 接受修订号 |
|---|---|---|---|---|---|
| V1 | 投料版（冻结） | 7.5–12.5 | 3–7 | 5 | 1 |
| V2 | 验收版（已发布） | 8–12 | 3.5–7.5 | 5 | 1、2 |

- 每个炉次在任一时刻只有一个配方版本结论；同一炉次被分配两个版本视为冲突并拒绝。
- 未显式切换的炉次沿用投料版（版本依据“投料锁定”）；切换记为“切换重判”并记录原版本；恢复记为“恢复旧版”。
- 结论带配方指纹。读取时若当前配方定义指纹与旧结论不一致，按当前定义重算，`recomputed` 为真，
  旧结论保留在 `acceptance_stored`，变化炉次列在 `acceptance_changed`。
- 切换/恢复是整批原子操作，失败不写库；`expected_revision` 为切换点乐观锁。同一幂等键重放不重复改判。
- 证据可追回：验收结论对应归一化成分与带原始行号的来料记录，接口为 `/api/runs/<id>/evidence?batch=`。

缺测元素贡献范围按0–100%计，未检出给上下界而非零；V2 目标区间同样不外推为生产工艺。
